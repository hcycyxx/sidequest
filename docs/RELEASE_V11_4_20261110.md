# SideQuest V11.4

## 本版功能

- 托盘右键菜单随主面板皮肤绘制：深色或手账配色、圆角、悬停高亮与一致字号，保留总结、历史、设置、显示与退出入口。
- 识别异常提示增加小关闭按钮。关闭只隐藏当前这次提示，不停止重连或清除后台错误记录；新错误仍可提醒。
- 通用提示增加与文字同色的进度条：处理中使用流动效果，成功提示在十秒内自动收起。没有准确百分比的操作不显示虚假的百分比。
- 日报生成有明确的处理中、成功、失败状态。文件生成后切换到成功提示并自动结束，不再长期停在“正在生成”。关闭处理中提示不取消后台生成。
- 保存、撤销、后台启停、列表获取、连通性检测、读取账号、扫码授权等操作均以实际返回结果结束等待状态。
- 模型回复缺少完整任务 JSON 时，在保留原任务的前提下尝试一次格式纠正；仍失败时进入已有退避重试。输出截断单独提示，不当作普通格式错误。不会把不完整数据落入任务文件。
- 模型回答上限调整为 8192 token；DeepSeek 官方接口开启 JSON 输出并关闭思考模式。其他兼容服务保留普通兼容请求格式。
- 网络断开、超时、服务故障、限流和认证失效分别提示；显示下一次自动重试等待时间。认证失败需用户重新登录或核对密钥，不做盲目快速重发。

## WorkBuddy 登录

在“模型与采样设置 → 模型连接 → 连接方式”选择 WorkBuddy。

1. 选择国内版或国际版，点击扫码登录；也可读取这台电脑已登录的客户端账号。
2. 用手机扫描二维码，在官方页面确认授权。可在 Chrome 中打开官方授权页。
3. 选择已登录账号，点击“使用此账号”，获取模型列表并选择模型。
4. 保存设置，再开始正常任务识别。

安装包包含独立 Node.js 运行组件，无需在目标电脑单独安装 Node。SideQuest 使用独立账号库和端口，不修改 Codex / CC Switch，不停止其他桥接。账号库与本机 Windows 用户绑定；换电脑需重新授权，不携带开发机账号。

只有用户选择 WorkBuddy 连接时才启动内置桥接。纯 API 方式保持可用。关闭设置页不停止已启动的桥接；正常识别时会检查内置桥接并在未运行时启动。
