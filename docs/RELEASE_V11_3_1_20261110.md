# SideQuest V11.3.1

本次只调整最小化与窗口折叠，沿用 V11.3 的设置页、任务、步骤和数据目录。

- 顶部最小化按钮直接隐藏到系统托盘，不再进入窄条模式，也不播放高度收缩动画。
- 托盘默认动作改为显示 SideQuest；也可通过托盘菜单“显示 SideQuest”恢复。
- 修复拖动结束后迟到的 pointermove / resize 请求重新开启原生拖动状态的问题。
- 每次拖动使用独立标识；原生端拒绝已结束或已被新布局取代的请求。前端在拖动结束请求返回前保持结束标记，停止继续发送尺寸更新。
- 增加窗口级松开指针监听；物理鼠标已松开但结束消息丢失时，解除残留拖动状态。
- 点击主线或支线折叠按钮时，明确取消旧拖动、切换布局版本、重新测量可见内容。折叠高度不受手动高度上限限制，仅受屏幕可用高度约束；展开后继续使用原手动高度上限。
- 保留已有阻尼动画、窗口宽度与任务数据。

安装包：`SideQuest_V11_3_1_FullSetup_20261110.exe`。

按用户要求只检查源码与编译打包，不运行界面、鼠标交互或模型功能测试。安装、正常打开供用户试用不计作功能验收；实际效果仍由用户确认。
