# SideQuest v11.5.0

- 顶部改为“当前进行任务”。在全部未完成任务中按卡片顺序选择，持续锁定直到确认完成；切换窗口、模型更新和重启不会主动换掉它。
- 完成当前任务后按待办卡片顺序接续下一项。拖动用于调整后续顺序，不抢占当前任务。
- 移除“下一步建议”版块；旧建议字段仍兼容历史数据和日报。
- AI 判断可能完成时，在面板中显示确认提示。“确认完成”沿用现有保存、蓝圈和烟花流程；“继续进行”保留已勾选步骤。
- 完成任务（包括勾完全部子步骤）后，通过 Windows 通知提示。通知使用系统原生组件，可能受系统通知设置和免打扰影响。
- 当前任务引用保存在本机界面设置中；原任务和登录数据目录不变。

## 复用选择

开发前检索了 [Super Productivity](https://github.com/super-productivity/super-productivity) 和 [Windows-Toasts](https://github.com/DatGuy1/Windows-Toasts)。前者截至核对时最近于 2026-11-10 提交，整体引入需要另一套桌面框架；此处继续二次开发 SideQuest 已有的排序和任务保存组件。后者未归档，最近提交为 2025-05-06，采用其现有 1.3.1 通知库，随包内置，不要求用户部署 Python 包。

最简方案：锁定当前任务 → 用户确认完成 → Windows 通知 → 按卡片顺序继续。

只做源码检查和编译打包，未运行界面、完成通知或模型功能测试。用户验收后再判断实际效果。
