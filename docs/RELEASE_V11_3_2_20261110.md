# SideQuest V11.3.2

- 保留 V11.3.1 的最小化到托盘和调整大小后折叠修复。
- 折叠期间由网页阻尼曲线统一控制高度，外层窗口直接跟随，避免两层弹簧叠加造成追赶与延迟。
- 原生尺寸更新改为非阻塞的界面线程调度，同时最多保留一项待处理更新，始终替换成最新尺寸。界面忙时不堆积旧帧。
- 一次更新窗口边界，仅在浏览器子控件未自动适配时补充布局。继续核对实际尺寸，并在动画结束后保持一致。
- 折叠期间保持高刷新调度，暂停会改动任务 DOM 的定时刷新；动画结束后恢复正常轮询。
- 桌面安装包采用醒目的名称：`SideQuest_最新安装包_V11.3.2.exe`。
- 桌面应用快捷方式：`SideQuest 最新版 V11.3.2`，指向已安装的程序，而不是安装器。

这次修改依据源码中的同步等待与重复布局开销。未运行帧率测量、界面测试或模型测试；实际流畅度由用户试用确认。
