# SideQuest V11.3

本版本延续已确认的主面板与设置页风格。

- 修复尺寸适配请求被旧回包吞掉的问题。收起与最小化使用版本序号、超时恢复、WinForms 界面线程布局和实际窗口尺寸校正。
- 新设置页采用与主面板一致的网页组件，无白色系统标题栏，支持拖动、最小化和关闭。
- 在“界面与日报”调整面板背景不透明度（20–100%）；不降低文字、图标和进度条透明度。
- 在“监测与内容”展开编辑系统提示词，保存后下一轮识别使用新规则。
- 默认提示词要求拆分可勾选步骤。步骤直接显示在任务下方，保存成功后播放蓝圈波纹和彩色烟花；沿用现有完成与撤销规则。
- 所有已知任务都保存在本地。模型漏报任务、超过原有任务数量上限、跨天或重启，不再导致未完成任务被丢弃。
- 底部“任务记录”可查看全部、未完成、已完成任务，每次显示 40 项。渲染数量与保存数量分开。
- 本地新增任务版本档案，记录任务与步骤变化；原任务文件仍为权威状态。旧版已经删除、且没有任何保存记录的任务不能凭空恢复。
- 保留用户已勾选步骤，即使下一轮模型遗漏步骤或只返回部分任务。
- 支持直接填写 DeepSeek 官方地址 `https://api.deepseek.com`、自己的 API Key 与官方模型名 `deepseek-flash`；官方直连默认关闭思考模式，回答上限为 4096 token。其他兼容接口的回答上限同样调整为 4096。
- 检测连通性仅查询 `/models`，不进行模型推理。凭据请求不自动跟随重定向。已有配置读取失败时阻止覆盖。

## 安装与数据

完整安装包：`SideQuest_V11_3_FullSetup_20261110.exe`。

程序目录沿用 `%LOCALAPPDATA%\Programs\SideQuestDesktop`。数据沿用 `%LOCALAPPDATA%\SideQuestDesktop\data`，更新不导入其他电脑的个人数据或密钥。

- 任务状态：`data\config\quest_state.json`
- 任务版本档案：`data\config\task_records_v11_3\tasks.sqlite3`
- 时间轴：`data\config\timeline_v10_4\timeline.sqlite3`
- 模型配置和自定义提示词：`data\config\llm.json`
- 原有未完成任务无需重新导入；重新打开主面板直接加载。

安装前退出旧程序。安装完成后可继续使用“SideQuest 最新版”桌面快捷方式，它指向同一安装路径。完整包包含 Python 和离线微软运行组件；本地模型桥接服务及云端 API 账号需自行配置。

## 构建范围

使用 `installer_v11_3/build_installed.spec` 生成程序，再由 Inno Setup 编译 `installer_v11_3/SideQuestSetup.iss`。复用已下载的微软离线组件。

按用户要求，没有启动应用、执行功能测试、调用模型或运行安装包；编译构建不等同于使用验收。实际动画、窗口透明度及各项交互由用户试用确认。
