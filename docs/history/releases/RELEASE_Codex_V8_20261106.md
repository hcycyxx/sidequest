# V8：外观与动画流畅度

本次仅优化界面绘制，不改变任务读写、勾选、暂停/继续及轮询行为。原版为 V7，备份在 `backups/codex_v8_20261106_102543/quest_window.py`。

## 主要变化

- 透明文字层从每次清空重建改成复用图形，仅同步变化的坐标和样式；保留独立列表视口裁剪、点击穿透和文字不透明。
- 文字排版缓存，皮肤/字号/缩放变化通过缓存键区分，长中英文标题的原有换行规则保留。
- 动画按时间截止点调度，目标60Hz，不再在每帧工作之后额外固定等待16ms。展开约240ms、收起约200ms，帧落后时按真实经过时间推进，支持中途反向切换。
- 收起时保留已有任务图层直到动画结束；不先删掉所有内容再缩窗。
- 不重复设置相同窗口尺寸；不每帧重复置顶、重新映射透明窗口；滚动条状态不变时不重建。
- 短促的悬停过渡、标题字重层级、进度与任务正文对齐、更轻的分隔线；四皮肤和完成蓝光/烟花沿用。
- 修复启动时仅加载皮肤名字/字体而没有应用对应配色的问题。

## 性能证据

同机约150%缩放，独立固定示例，83个列表画布项。基线为备份中的V7源码，测试脚本 `bench-v8.py`。

| 指标 | V7 | V8（复测） |
|---|---:|---:|
| 透明文字同步中位耗时 | 9.14ms | 0.31ms |
| 同步 render 中位耗时 | 13.99ms | 7.55ms |

这是隔离 Tk 示例中的绘制调用开销，不是桌面合成帧率，也不保证所有机器达到60FPS。首次建立文字层仍需完整创建图形，之后的稳定同步才走缓存。

检查通过：50次同步复用同一批目标图形；全透明度与半透明来回切换后文字保留；重复及中途反向开合；窄条切换；四皮肤；无 Tk 回调错误。AST 检查确认任务 IO、任务/步骤切换、暂停及 tick 未改动。

未通过截图工具重新验收真实窗口画面。本次没有调用真实模型做测试，没有改任务 JSON、API配置或采样服务。只重新加载 UI 时，后台服务保持原来的运行/暂停状态。

源码 UI 仍从 `ui/quest_window.py` 启动。安装包/EXE 没有重新打包。V7 的引擎更新只有在引擎进程重新启动后才会加载，本次只重启UI。
