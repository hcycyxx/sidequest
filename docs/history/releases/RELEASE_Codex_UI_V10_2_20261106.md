# SideQuest UI V10.2 · 外框跟随收起

Jack 反馈：支线文字收起后，外层窗口高度保留，底部出现大块空白。

本版修正：

- 以当前可见子元素的底边计算自然内容高度，避免把已拉长的容器高度作为收缩目标。
- 展开/收起结束和拖动结束时重新提交最终高度。
- 高度请求串行合并，仅保留最新目标，避免旧请求盖过新目标。
- 后台在隐藏或调整大小期间未采用的高度请求，不再被前端错误记为已完成。
- 调整尺寸时同步更新 WebView 桌面宿主；位置移动继续复用 V10.1 本机快速路径。
- 保留原阻尼、165Hz 调度目标、样式和任务后台。

新增独立文件，V10/V10.1 原文件及版本包均保留。

启动：`launch_sidequest_v10_2.ps1 -ReplacePanel`。

按 Jack 要求，没有运行测试、截图、浏览器检查或帧率测量。
本次只重启界面，效果由 Jack 直接试用确认。
