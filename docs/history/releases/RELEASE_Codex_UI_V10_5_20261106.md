# SideQuest UI V10.5 · 窗口停留统计

按 Jack 决定，时间轴只统计前台窗口停留时长，不判断有效工作或键鼠空闲。

- 新增独立轻量计时线程，约每2秒读取前台窗口、窗口标题和应用名；无截图、OCR或模型调用。
- 窗口或标题改变即结束上一段、开启下一段，同一窗口连续累计。
- 标题栏和应用可识别时使用实际名称；键鼠无操作仍计入停留。
- 暂停观察、锁屏、无可读前台窗口、应用未运行及休眠/采样中断超过6秒的间隔不补计。
- 使用单调时钟累计时长，检测系统时钟跳变，不把异常间隔加入总数。
- 时间轴打开期间约每2秒刷新，当前段注明“正在停留”。保留纵向排列、横向时长条、完成与恢复事件。
- 停留记录存入既有本地时间轴数据库的独立 dwells 表，旧采样及任务事件不删除。
- 新统计只使用启用V10.5后的停留记录，不把过去空闲过滤的采样推算混入新口径；不能准确补回旧窗口停留时间。
- 系统中断或强制替换界面时只保留最后一次已记录的时长，不外推停机时间。窗口切换记录误差约为采样间隔。

保留皮肤、贴边隐藏、阻尼、165Hz目标及既有任务后台。
启动：`launch_sidequest_v10_5.ps1 -ReplacePanel`。

按 Jack 要求没有运行测试；保存新版本并只重启界面，由 Jack 试用。
