## 卡片

- 长按标题或说明文字约0.3秒，卡片悬浮后可上下拖动。
- 短按标题仍展开详情，提前移动超过8px取消长按；步骤、勾选、按钮等控件不触发文字拖动。
- 标题的触屏划动在长按前转为正文滚动；保留原把手、键盘排序、边缘滚动与顺序保存。
- 拖动后250ms内拦截误点击，避免刚松手便展开详情或触发其他按钮。
- 长按等待期间暂缓列表刷新；取消、窗口失焦、滚轮操作和Escape会解除等待。
- 卡片拾起时轻微放大并抬升，与 CRM 的悬浮拖动语言保持一致。

## 烟花

- 保留小蓝圈原效果。
