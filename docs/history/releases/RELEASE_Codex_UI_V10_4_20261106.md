# SideQuest UI V10.4 · 贴边隐藏修复与时间轴

## 贴边隐藏

- 鼠标操作复选框后，不再因遗留焦点持续阻止隐藏。
- 鼠标离开正文释放焦点占用；窗口失去焦点时关闭菜单并释放设置占用。
- 自动隐藏的占用状态按顺序提交并合并，防止并发回包将旧的“保持展开”状态重新写回。
- 真正打开菜单、设置、保存或拖动时仍保留必要保护，不改用户的自动隐藏开关选择。
- 左右停靠、750ms 延迟和原阻尼效果继续沿用。

## 时间轴

- 主界面底部新增“时间轴”按钮，点击切换到同窗口、同皮肤的时间轴页面，右上角返回任务。
- 日期选择、刷新、纵向事件排列；最近记录在上方，每批100条，可继续显示更早记录。
- 每段活动显示开始/结束、窗口活动标题、估算持续时长；横向柱长按当日最长活动段同比例展示。
- 完成事件使用任务已有 completed_at/completedAt/done_at。任务建立时间与完成时间分开展示。
- 手动恢复和撤销另外记录事件，保留发生过的完成记录，不假装撤销抹去了历史。
- 当前任务没有完成时间时不猜测；单次采样不补造时长。

## 数据口径

活动数据来自既有 `config/win_log.jsonl`，没有增加屏幕抓取或模型调用。
只归档时间、窗口标题、应用名和空闲秒数，不复制 OCR、文档正文或密钥。
连续有效样本之间最长接受90秒间隔；空闲达到60秒或日志中断时不外推工作时间。
时长属于窗口活动的采样估算，不等于某项任务的精确工时；任务建立到完成的整段跨度不会冒充实际用时。
任务完成事件单独放入同一纵向时间轴。当天汇总中的“完成记录”是事件条数，不代表当前仍完成的任务数。

增量归档和事件保存于 `config/timeline_v10_4/timeline.sqlite3`，目录自行忽略 Git。
记录会继续本地积累；安装前已被旧日志轮转删除的历史无法补回。
后台每10秒启动一次轻量增量归档线程，避免在动画循环中解析大日志。
时间轴打开时读取存档并补读已有日志，打开期间每10秒更新。
源日志过大时分批归档，页面标明仍有更多记录，后续刷新可继续。
