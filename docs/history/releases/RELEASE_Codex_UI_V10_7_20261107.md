# SideQuest UI V10.7 · 完成交互与柔和配色

Jack 反馈左侧完成/步骤按钮点击未生效，要求局部蓝圈烟花、先慢后快的折叠离场，并调整不协调的等级配色。

## 点击与保存

- 操作编号不再只依赖 `crypto.randomUUID()`。该接口在部分非安全上下文或嵌入式渲染环境中不可用；增加随机字节与本地计数回退，避免请求在到达后台前中断。
- 保留后台文件锁、身份核对、显式目标状态和去重规则，不自动猜测或改写未知任务。
- 响应成功后核对任务或步骤目标状态，再播放成功动效。
- 保存失败或状态未确认时保留任务，错误在该任务旁展示；不播放庆祝，也不自动重发。
- 已保存操作保留撤销入口；完成任务进入既有完成历史。

## 完成效果

- 圈从小放大，使用柔和浅蓝，外圈直径约72px。
- 3组微型烟花、每组4条短光点，集中于鼠标附近约40px范围，约0.8秒内自动清理。
- 键盘激活以按钮中心为反馈位置；步骤复选框使用最近的点击位置。
- 非最终步骤仅局部反馈。整项完成或最后一步完成后，先确认保存，再从下方折叠收起。
- 离场约740ms，前段缓慢、中段加速、末段轻收尾；周围内容跟随实际高度让位。
- 减少动画偏好下使用直接状态更新，不播放粒子效果。
