# SideQuest V11.2 完整安装包

## 已确认的原因

用户提供的另一台电脑日志显示：部分模型返回 `message.content=None`，旧解析直接调用 `.strip()` 导致异常。
连续失败后进入最长8分钟重试等待；修改模型后旧等待未清零。
随后换到已兼容的模型，正常完成“主线1、支线1”更新，说明后台并非一直没有启动。
“正在启动后台”属于已经完成启动但未清掉的界面提示。

## 修复

- 新推理模块先检查响应结构与最终文本，兼容文本片段数组；空结果、截断和不兼容结构明确提示，不再抛None.strip。
- 改模型、接口地址或密钥会清除旧重试等待，继续使用原任务JSON规则与原正常分析流程。
- 日志遥测记录分析阶段、提交时间、成功时间和具体错误类别，不输出密钥或模型正文到状态栏。
- 启动操作结束会更新提示；即使本轮没有任务变化，底部也显示最近识别时间或等待首次识别。
- 模型失败在主面板直接显示原因；进程活着不再让用户误以为识别一定成功。

## 完整安装

桌面产物：`SideQuest_V11_2_FullSetup_20261107.exe`。
Inno Setup构建的单文件安装器，内含Python、CPU OCR、界面资源、WebView2和.NET4.8离线安装程序。
只有缺少微软组件时才安装；.NET安装可能要求管理员确认或重启。

安装目录：`%LOCALAPPDATA%\Programs\SideQuestDesktop`。
使用数据：`%LOCALAPPDATA%\SideQuestDesktop\data`，不在程序文件目录，升级与卸载默认保留。
桌面快捷方式：`SideQuest V11.2`。
安装版直接使用固定本地目录，不再经过旧便携版缓存复制。

首次设置自动打开，可点击“导入旧配置”选择旧便携版 `data/config/llm.json`。
只填入地址、模型和密钥，检查保存后由用户选择启动识别；不会自动运行网络测试。
目标电脑的本地AI接口服务仍需存在并运行，本包不包含模型服务、账号或大模型权重。
安装包不嵌入当前机器密钥、客户记录或窗口历史。

后台启动写就绪/失败状态和心跳；隐藏后台异常只写本地日志并退出，不弹隐藏的阻塞错误框。
原便携版和桌面源码版不覆盖，安装前应退出旧便携版，避免同时运行两份。
