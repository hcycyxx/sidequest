# SideQuest UI V10.8 · 圆角卡片与拖动排序

## 任务卡片

- 列表中的各项任务使用统一12px圆角卡片，沿用现有皮肤、字体和柔和等级色。
- 标题按钮及建议区域悬停使用圆角；标题禁用意外文字选择，说明文字仍可复制。
- 每张卡片右上角新增拖动把手。上下拖动时卡片抬起，原位置保留占位，其他卡片平滑让位。
- 接近正文上下边缘时自动滚动。松手后落位并保存，Escape、指针取消或窗口失焦恢复原顺序。
- 把手支持 Alt＋上/下方向键移动。
- 手动顺序保存在 ui_v10.json 的 cardOrder，不改任务内容、主支线分类或 AI 优先级。新任务仍会保留。
- 菜单增加“恢复优先级排序”，清空手动显示顺序。
- 主线重点区域仍保持固定位置；拖动排序作用于其下的任务列表。
