SideQuest V11.3 完整安装版

安装与更新
1. 退出旧版后运行 Setup EXE。程序和使用数据沿用原路径，更新不会清空任务或接口配置。
2. 程序目录：%LOCALAPPDATA%\Programs\SideQuestDesktop
3. 数据目录：%LOCALAPPDATA%\SideQuestDesktop\data
4. 安装后可继续使用“SideQuest 最新版”快捷方式。卸载默认保留使用数据。

设置与连接
5. “更多 → 外观与设置 → 模型与采样设置”打开统一风格的新设置页。
6. 支持本地桥接和官方兼容接口。DeepSeek 官方地址为 https://api.deepseek.com，填写自己的 API Key 与 deepseek-flash 模型名；不需要安装 WorkBuddy。
7. 本地地址 127.0.0.1:8899 只指向当前电脑；使用此地址需先启动该电脑的桥接服务。
8. 获取模型、检测连通性只查询 /models，不执行模型推理。模型列表可访问不代表每个模型均可正常识别任务。
9. 首次配置可导入旧版 llm.json。保存后可点击“启动识别”。
10. “界面与日报”可调背景不透明度；文字、图标、进度条不随背景淡化。
11. “监测与内容”下方可展开编辑任务识别提示词。请保留 JSON 输出结构；保存后下一轮识别使用新规则。

任务与步骤
12. 保留所有已知任务，未完成任务跨天、重启后继续显示。
13. “任务记录”查看全部、未完成、已完成任务，分批加载显示，不限制保存数量。
14. 模型自动把任务拆成可勾选步骤。勾选保存成功后播放蓝圈与彩色烟花；完成所有步骤沿用现有规则完成父任务。
15. 任务状态位于 data\config\quest_state.json，版本档案位于 data\config\task_records_v11_3\tasks.sqlite3。
16. 旧版已经删除、且没有任何存档的任务无法凭空恢复。本版从仍保存的任务继续累计记录。

问题反馈
17. 后台状态见主面板“外观与设置 → 后台状态”。日志位于 data\logs。
18. 本包包含 Python、OCR 和离线微软运行组件，不含个人密钥、客户记录或模型桥接服务。
19. 按用户要求只完成源码检查与编译打包，没有运行应用功能测试或调用模型验收。
