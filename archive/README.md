# 历史文件归档

旧文件原样保留，最新版从仓库根目录 `sidequest_latest.py` 启动；当前安装源码在 `installer_v11_5/`。

| 文件夹 | 内容 |
| --- | --- |
| `legacy/` | V9/V10 历史入口和启动脚本 |
| `installers/` | 旧安装版与便携版构建源码 |
| `../docs/history/releases/` | 历史发布说明 |
| `../docs/history/notes/` | 旧设计说明与交接记录 |

归档是查阅用的原始快照，内部相对路径与文字保留历史上下文，不作为当前启动或构建入口。要完整运行或构建旧版本，请在独立目录检出对应 Git tag/提交；请勿把归档脚本与当前后台混用。

目录整理没有删除历史文件，也没有改变当前软件与已发布安装包。
