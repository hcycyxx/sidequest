SideQuest V11.4 完整安装版

1. 安装后双击桌面“SideQuest 最新版 V11.4”打开。更新沿用原任务和配置，并保留历史版本安装包。
2. 程序目录：%LOCALAPPDATA%\Programs\SideQuestDesktop
3. 数据目录：%LOCALAPPDATA%\SideQuestDesktop\data
4. 托盘右键菜单采用主面板风格；最小化仍直接收到托盘。
5. 异常提示右侧小 x 可关闭当前提示，不停止后台重试。进度条颜色与文字一致。
6. 日报生成结束后会提示已完成并自动收起；不会长期停在生成中。
7. 模型偶发返回普通文字、错误 JSON 或被截断时，保留原任务，尝试纠正或按规则重连。
8. WorkBuddy：进入模型设置，连接方式选 WorkBuddy；选择区域后扫码，在官方页面确认，再选用账号、获取模型并保存。
9. 本机已有登录时可读取本机账号；新电脑需首次授权。安装包不包含任何开发机账号或密钥。
10. 已包含 Node.js，不需另外安装。内置桥接独立运行，不修改 Codex 或 CC Switch，不停止其他桥接。
11. 云端或本地 API 继续选“API 接口”。DeepSeek 官方地址为 https://api.deepseek.com，填写自己的 API Key 和模型名。
12. 网络故障会重试并显示等待时间；登录或密钥失效需要重新授权，单靠重连不能解决。
13. 后台日志位于 data\logs，内置桥接日志位于 data\workbuddy_v11_4\bridge.log。
14. 本次未运行应用功能测试、扫码验收或模型调用，实际效果由用户试用确认。
