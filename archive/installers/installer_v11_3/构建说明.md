# V11.3 安装包构建

适用 Windows 10 2004+ / Windows 11 x64。此次实际构建环境为 Python 3.12.8、PyInstaller 6.20.0 和本机 Inno Setup 6；UI 依赖复用已有 `SideQuestV10Runtime` 环境。

## 构建前准备

1. 安装 Python 3.12（包含 tkinter），按 `requirements-build-v11_3.txt` 准备构建和 OCR 依赖。
2. 使用 `python -m venv "$env:LOCALAPPDATA\SideQuestV10Runtime"` 创建独立 UI 环境，再用其中的 Python 安装根目录 `requirements-ui-v10.txt` 中的依赖。环境已存在时先核对，不覆盖已有环境。
3. 准备 Inno Setup 6。默认路径为 `%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe`，其他位置通过 `-ISCC` 指定。
4. 从微软官方渠道准备 WebView2 x64 离线安装器 `MicrosoftEdgeWebView2RuntimeInstallerX64.exe` 和 .NET Framework 4.8 离线安装器 `NDP48-x86-x64-AllOS-ENU.exe`，放进 `.installer_build_v11_3/prerequisites`；本源码包不重复分发它们。检查来源与许可后再使用。

本次复用上版已有的两个离线安装器，不改变系统软件或 Python 环境。WebView2 是应用的嵌入式渲染组件，不会启动 Edge 浏览器。

## 编译

在仓库根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\installer_v11_3\build_release.ps1
```

每次使用新的时间戳构建目录，遇到已有同名安装包会停止。脚本仅编译，不安装、不启动应用、不检测模型接口。

当前有效描述文件为 `build_installed_v2.spec` 和 `SideQuestSetup_v4.iss`。早期同目录草稿不是交付构建入口。打包逻辑从 V11.2 沿用，新增两个设置外观模块并使用 V11.3 安装资源。

首次提供的已编译产物位于 `deliveries_v11_3_20261109/SideQuest_V11_3_FullSetup_20261109.exe`。再次构建默认放入独立子目录，不覆盖本产物。
